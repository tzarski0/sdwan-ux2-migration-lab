Step 7: Cleanup (Optional)¶

Optional step

This step is optional. Do it if you have time left after Step 5.

Do this cleanup only after all sites have been moved to configuration groups and policy groups with the new site IDs, and the network has been running stable for a few weeks. Until then, keep the UX 1.0 configuration in place so that you can still roll back a site if needed.

Once you're confident, remove what is no longer used:

  • Deactivate the old UX 1.0 centralized policy in Configuration → Classic → Policies.
  • Remove the UX 1.0 configuration from SD-WAN Manager: device templates, feature templates, centralized policy and policy lists.
  • Go to Configuration → Topology and edit branches-hub-and-spoke-v2. In both rules (TLOC and Route), remove SITE_10 from the matched sites so that only dc remains. Save the policy and deploy it again.
  • Go to Configuration → Network Hierarchy and remove the old sites that are no longer used: SITE_10, SITE_21, SITE_22 and SITE_23.

Tip

Keep the CSV files you exported from the device templates until you are confident no rollback is needed.

Congratulations, you have completed the lab!
